# KORE Brand Assets

Alle Logos liegen als **echte Vektorpfade** vor (Schrift als Kurven eingebettet) —
sie sehen in jedem Programm identisch aus, ohne dass Fonts installiert sein müssen.
SVG = beliebig skalierbar (Druck, Web, Folierung). PNG = fertige Raster-Exporte.

## Schrift & Farben
- Wortmarke: **Cormorant** (Light) · Zusatz: **Jost** (gesperrt)
- `#1C1A17` Ink (fast-schwarz) · `#9E8460` Brass · `#C9B898` Brass hell
- `#F7F4EF` Creme (Hintergrund) · `#FDFCFA` Weiß · `#524E46` Mid-Grau

## Dateien
| Datei | Einsatz |
|---|---|
| `kore-wordmark-{ink,white,brass}.svg` | Reine Wortmarke „KORE" — Web, Präsentationen, Folien |
| `kore-logo-stacked-{ink,white}.svg` | KORE + „RETAIL PLATFORM" gestapelt — **Standardlogo**, Briefkopf, Titelseiten |
| `kore-logo-horizontal-{ink,white}.svg` | K-Kachel + Wortmarke nebeneinander — Kopfzeilen, E-Mail-Signatur, Partnerlisten |
| `kore-monogram-{brass,ink}.svg` | Freistehendes „K" — Wasserzeichen, Muster, Gravur |
| `kore-tile-{ink,cream}.svg` | „K" auf abgerundeter Kachel — Avatare, Social-Profilbilder |
| `kore-appicon.svg` / `png/kore-appicon-1024.png` | App-Icon (randlos, iOS rundet selbst) |
| `kore-favicon.svg` | Browser-Favicon |
| `kore-og-banner.svg` / `png/…-1200x630.png` | Social-/Link-Vorschau (Open Graph) |
| `briefkopf/kore-briefkopf-logo.svg` | Briefkopf-Logo (gestapelt, Ink + Brass) |
| `briefkopf/kore-briefkopf-a4.svg` + `-vorschau.png` | Komplette A4-Briefvorlage (Kopf + Fußzeile) |
| `png/` | Hochauflösende PNG-Exporte (2048 px Breite) |
| `legacy/` | Alte, Text-basierte SVGs (nicht mehr verwenden — Schrift nicht eingebettet) |

## Regeln (Kurzfassung)
- Auf hellem Grund: `-ink`-Varianten · auf dunklem Grund: `-white`-Varianten
- Schutzraum: mindestens Höhe des „K" rundum freihalten
- Wortmarke nie stauchen, neu einfärben oder mit Effekten versehen
